Neural Network API

Layers and losses in vc::nn for MLPs and CNNs.

Layer Base Class

template <typename T>
class Layer {
public:
    virtual ~Layer() {}
    virtual Tensor<T> operator()(const Tensor<T>& x) = 0;
    virtual vc::vector<Tensor<T>*> parameters();
    virtual void to(const std::string& device);
};

All trainable modules implement this interface. Sequential stores layers via shared_ptr<Layer<float>>.

Dense

Constructor

vc::nn::Dense<float>(size_t in_features, size_t out_features, std::string activation = "none")
  • Xavier/Glorot weight init.
  • Bias initialized to 0.
  • Supported activation values: none, relu, softmax, sigmoid, tanh, leaky_relu, gelu, silu.

Forward

Tensor<float> y = dense(x);

Computes y = x * W^T + b, then optional activation.

Conv2d

Constructor

vc::nn::Conv2d<float>(int in_channels, int out_channels, int kernel_size, int stride = 1, int padding = 0)

Input shape is batch, channels, height, width.

Weight shape is out_channels, in_channels, kernel_h, kernel_w.

Example

Sequential model;
model.add(std::make_shared<vc::nn::Conv2d<float>>(1, 32, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());

MaxPool2d

Constructor

vc::nn::MaxPool2d<float>(int kernel_size, int stride = -1, int padding = 0)

If stride is -1, stride defaults to kernel_size.

Flatten and ReLU Layers

vc::nn::Flatten<float>()
vc::nn::ReLU<float>()
  • Flatten converts N,C,H,W into N, C*H*W.
  • ReLU layer is a module wrapper around Tensor::relu().

Loss Functions

CrossEntropyLoss

vc::nn::CrossEntropyLoss<float> criterion;
Tensor<float> loss = criterion(logits, one_hot_targets);

Expected target format is one-hot encoded classes.

MSELoss

vc::nn::MSELoss<float> mse;
Tensor<float> loss = mse(predictions, targets);

CNN Training Example

Sequential model;
model.add(std::make_shared<vc::nn::Conv2d<float>>(1, 32, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());
model.add(std::make_shared<vc::nn::MaxPool2d<float>>(2, 2));
model.add(std::make_shared<vc::nn::Conv2d<float>>(32, 64, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());
model.add(std::make_shared<vc::nn::MaxPool2d<float>>(2, 2));
model.add(std::make_shared<vc::nn::Flatten<float>>());
model.add(std::make_shared<vc::nn::Dense<float>>(64 * 7 * 7, 128, "relu"));
model.add(std::make_shared<vc::nn::Dense<float>>(128, 10, "none"));

model.to("cuda");
