Sequential API

High-level model container for forward pass, training, evaluation, and checkpointing.

Construction Patterns

Pattern A: start empty and add layers

Sequential model;
model.add(std::make_shared<vc::nn::Conv2d<float>>(1, 32, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());

Pattern B: variadic constructor

Sequential model(
    vc::nn::Dense<float>(784, 2048, "relu"),
    vc::nn::Dense<float>(2048, 1024, "relu"),
    vc::nn::Dense<float>(1024, 10, "none")
);

Core Methods

  • void add(std::shared_ptr<vc::nn::Layer<float>> layer): appends a layer.
  • Sequential& to(const std::string& device): moves all parameters to cpu or cuda.
  • vc::Tensor<float> operator()(const vc::Tensor<float>& x): model forward pass.
  • vc::vector<vc::Tensor<float>*> parameters(): all trainable parameters.

Training: fit

void fit(
    std::vector<Sample>& train_dataset,
    int epochs = 50,
    float learning_rate = 0.001f,
    int batch_size = 1024,
    int patience = 0,
    float min_delta = 1e-5f,
    std::vector<Sample>* val_dataset = nullptr
);

Supports SGD and Adam via compile(). Uses fused GPU cross-entropy path when tensors are on CUDA.

Early stopping: if patience > 0 and validation loss does not improve by min_delta, best weights are restored.

Input shapes: CNN inputs should be stored per sample as C,H,W (for MNIST: 1,28,28). Dense-only inputs can remain flattened.

Evaluation and Checkpointing

  • void evaluate(std::vector<Sample>& test_dataset, int batch_size = 64)
  • void save(const std::string& filepath)
  • void load(const std::string& filepath)

save/load use binary float32 parameter streams in layer order. This is intentionally compact and fast.

Complete CNN Example

Sequential model;
model.add(std::make_shared<vc::nn::Conv2d<float>>(1, 32, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());
model.add(std::make_shared<vc::nn::MaxPool2d<float>>(2, 2));
model.add(std::make_shared<vc::nn::Conv2d<float>>(32, 64, 3, 1, 1));
model.add(std::make_shared<vc::nn::ReLU<float>>());
model.add(std::make_shared<vc::nn::MaxPool2d<float>>(2, 2));
model.add(std::make_shared<vc::nn::Flatten<float>>());
model.add(std::make_shared<vc::nn::Dense<float>>(64 * 7 * 7, 128, "relu"));
model.add(std::make_shared<vc::nn::Dense<float>>(128, 10, "none"));

model.to("cuda");
model.compile("adam");
model.fit(train_samples, 25, 0.001f, 64, 5);
model.evaluate(test_samples, 64);
model.save("docs/weights.json");
